# Scan AI — от сомнений к ясности / EUR/USD

Новая отдельная композиция `scan-ai-emotion` существующего Crypto Volk Motion Engine. Предыдущие шесть успешных роликов и исходники сохранены. Использованы прежние фирменные панели, настоящие локальные шрифты Montserrat / Roboto Mono, графики, кинетическая типографика, исходные прозрачные плашки и архитектура рендера.

## Что изменено

- Новая озвучка и независимая разметка речи. Никаких таймкодов из предыдущих рекламных кампаний.
- Два оригинальных пользовательских видеоклипа включены в монтаж. Начало — сомнения и вопросы «ПОКУПАТЬ? / ПРОДАВАТЬ? / ЖДАТЬ?». После демонстрации продукта — радость от понятной структуры анализа.
- Нативная типографика находится вне консервативных областей лица на всех кадрах. Радостный клип кадрирован так, чтобы исключить процент доходности в верхней части исходника. Положительная эмоция связана с понятной логикой, без заявления о гарантированном заработке.
- На фразе «меньше одной минуты» — плавное сканирующее раскрытие DARK → LIGHT. Фон Navy `#050718` сменяется Ivory `#F3EFE9`, а текст, свечи, кнопки, панели, тени и линии переходят в соответствующую светлую тему. Таймер `< 01:00` — иллюстрация озвученной идеи, а не выдуманный замер работы бота.
- Непрерывная демонстрация: EUR/USD → краткосрочная / среднесрочная торговля → выбор среднесрочного режима → AI-анализ → LONG, вход, стоп, три цели и объяснение уровней.
- Финал: именно **3 АНАЛИЗА БЕСПЛАТНО**, затем «ПОПРОБУЙ И ОЦЕНИ». Слово «анализы» не заменено на «сигналы».
- Второстепенный добавленный текст преимущественно 38–46 px, минимальный кегль 36 px. Настоящие шрифты, стабильные буквы, последовательное раскрытие информации.
- Только оригинальные очищенные PNG Crypto Volk и Scan AI. Внешние квадратные / прямоугольные подложки отсутствуют; оригинальная тёмная внутренняя часть неоновой плашки сохранена.

## Видео и звук

Экспорт: **1080×1920, 9:16, 30 fps, H.264/AAC, 39,5 с / 1185 кадров**.

Новая исходная озвучка сохранена побайтно в `assets/audio/scan-ai-emotion.mp3`. Декодированная длительность **37,48571428571429 с**, финальное тихое удержание **2,01428571428571 с**. Музыка, дополнительная речь и изменение скорости озвучки не добавлены. Выходной AAC — 256 кбит/с.

`compositions/scan-ai-emotion-words.json` содержит хеш аудио, слова и акустические границы новой записи. CTC-разметка имеет сетку 40 мс; анимация — 1/30 с. Это разрешение разметки, а не обещание точности до аудиосэмпла. Написания Crypto Volk / Scan AI / стоп-лосс восстановлены по пользовательскому сценарию.

Исходные клипы:

- `assets/video/trader-despair.mp4`: 5 с, 1080×1920, 30 fps; используется с замедлением 0,86× в начале, без зацикливания.
- `assets/video/trader-joy.mp4`: 5 с, 1080×1920, 30 fps; используется отрезок приблизительно 0,45–4,41 с в сцене ясности.

Оба файла сохранены целиком и побайтно, без аудиопотоков; хеши в `assets/video/emotion-sources.json`. Монтажное кадрирование не меняет исходные MP4. Видео на телефоне внутри предоставленного клипа — часть декоративного исходника; отдельная демонстрация EUR/USD нарисована программно как стилизованный интерфейс, без утверждения о точном виде реального приложения.

## Запуск

Требуются Node.js, Chromium и FFmpeg с libx264. Для контактного листа — Python 3 и Pillow. При необходимости задать `CHROMIUM_PATH`.

```sh
npm ci --cache .npm-cache
npm start
```

Открыть `http://localhost:4173/composition.html?composition=scan-ai-emotion`.

```sh
npm run check:emotion
npm run stills:emotion
python scripts/contact-sheet.py --composition=scan-ai-emotion
npm run render:emotion
npm run check:emotion:media
```

## Редактирование отдельных сцен

- `compositions/scan-ai-emotion.js` — девять независимых функций сцен.
- `compositions/scan-ai-emotion.json` — границы сцен, речевые якоря, кадрирование и скорость исходных клипов, цена / уровни и превью.
- `compositions/scan-ai-emotion-script.txt` — точный пользовательский сценарий.
- `docs/scan-ai-emotion-brief.txt` — полный исходный бриф.
- `components/forex-journey.js` — переиспользуемый путь: пара → срок → анализ → готовый сценарий. Существующий компонент графика `drawTradingChart` используется повторно.
- `components/video-layer.js` — переиспользуемый видеослой с последовательным выбором исходного кадра и зоной лица. `prepareFrame(time)` — дополнительный необязательный хук плеера. Композиции без видео сохраняют прежний синхронный путь.

Новые слои не требуют переписывать архитектуру. Для ручного экспорта через браузер сначала `await window.render(time)`, затем снимок canvas. Промежуточные последовательности кадров не сохраняются и не входят в Git.

## Выходные файлы и проверка

MP4: `output/crypto-volk-scan-ai-emotion.mp4`. В `output/scan-ai-emotion/` — 22 ключевых превью, контактный лист, отдельный лист DARK → LIGHT и отчёты.

`check:emotion` проверяет все 1185 кадров: реальные границы глифов, безопасную область, кегль, смешение алфавитов, отсутствие текста в области лица, стабильность осевших надписей, речевые якоря, настоящие шрифты, оригинальные прозрачные брендовые PNG и хеши предыдущих MP4. В ключевых кадрах отдельно проверяются пересечения текста / бренда. Фактически нарисованные линии LONG проверяются в canvas. Видеокадры сверяются с независимым декодированием FFmpeg; исходные видео — по хешу и параметрам потоков.

`check:emotion:media` выполняет полное декодирование финального MP4, сравнение ключевых сцен и переходов с программным рендером, проверку реальных кодеков / разрешения / fps / длительности / числа кадров, сдвига голоса и финальной тишины. Проверяет воспроизведение, перемотку и HTTP Range 206.

После добавления поддержки видео шесть контрольных кадров прежних композиций `scan-ai-oil` и `scan-ai-clarity` сравнены со старым плеером: пиксели идентичны. Результат в `player-regression.json`. Предыдущие финальные MP4 не изменены.
