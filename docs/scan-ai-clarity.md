# Scan AI — DARK → LIGHT

Новая отдельная композиция `scan-ai-clarity` использует архитектуру Crypto Volk Motion Engine. Обе предыдущие успешные версии, их озвучка, композиции и финальные MP4 сохранены.

## Что изменено

- Новая озвучка заменяет предыдущую только в новой композиции. Исходный MP3 скопирован без изменений; музыки, изменения темпа, высоты голоса и шумоподавления нет. Экспорт звука — AAC 256 kbit/s.
- Добавлена сцена «КАК ПОСТУПИТЬ ПРАВИЛЬНО?» с замедлением и остановкой графики.
- На слове «Смотри» сканирующая линия раскрывает Ivory поверх Navy. Один и тот же текст программно рисуется в двух темах через пространственные маски, без генерации изображений или морфинга букв.
- После перехода карточки, сетки графиков, свечи, уровни, тени, курсор, числа и подписи используют полноценную светлую тему. Основной фон — `#F3EFE9`, основной текст — `#050718`. Фирменные `#7A52EE` / `#5FCDC9` сохранены в оформлении; для небольших цветных надписей используются более тёмные оттенки с достаточным контрастом.
- Непрерывная демонстрация «рынок → актив → AI-анализ → сценарий» использует существующий переиспользуемый компонент. Во время объяснения появляются только актуальные подписи уровней.
- Финальные карточки и крупное слово «БЕСПЛАТНО» оформлены в светлой теме. Оригинальный светлый логотип читается на специально нарисованной округлой Navy-поверхности; она является частью композиции, а не фоном внутри изображения.
- Оба оригинальных прозрачных брендовых asset сохранены без перерисовки. SHA-256 исходников и очищенных PNG, прозрачные внешние края проверяются до рендера.
- Минимальный размер программного текста — 36 px, основные интерфейсные подписи — 38–46 px. После появления буквы стабильны.

## Редактирование

- `compositions/scan-ai-clarity.js` — девять отдельных функций сцен: hook, opinions, knowledge, question, product, logic, learning, free, cta.
- `compositions/scan-ai-clarity.json` — границы сцен, тайминги, переход темы, список превью и выходные файлы.
- `compositions/scan-ai-clarity-script.txt` — точный пользовательский сценарий.
- `components/fintech.js` — общая графика и изолированная палитра каждой композиции; тема по умолчанию остаётся прежней тёмной.
- `components/theme-reveal.js` — новый переиспользуемый переход двух тем через сканирующую линию.
- `components/trading-setup.js` — общий пользовательский путь и согласованная модель демонстрационной сделки.

Демонстрационный LONG: Stop Loss 99 000 < Entry 100 000 < TP1 101 000 < TP2 102 000 < TP3 103 000. FVG 100 300–100 620, Order Block 99 300–99 650. Это стилизованная демонстрация, а не точный скриншот продукта или актуальная торговая рекомендация. Метка «ДЕМО» видна в сценах сценария и объяснения. Светлая тема означает ясность представления, а не отсутствие торгового риска.

## Запуск

```sh
npm ci --cache .npm-cache
npm start
```

Открыть `http://localhost:4173/composition.html?composition=scan-ai-clarity` (порт выводит сервер).

```sh
npm run check:clarity
npm run stills:clarity
npm run render:clarity
npm run check:clarity:media
```

Нужны Node.js, Chromium (`/usr/bin/chromium` или `CHROMIUM_PATH`), FFmpeg и ffprobe. Для рендера и проверки не нужны ASR-модели: готовое выравнивание находится в проекте. MP4: `output/crypto-volk-scan-ai-clarity.mp4`. Превью, контактные листы и отчёты: `output/scan-ai-clarity/`.

Проверка охватывает все 1395 кадров: реальные шрифты, минимальный кегль, границы надписей, алфавиты и словарь подписей; ключевые кадры дополнительно проверяются на пересечения, стабильность текста, контраст светлой темы и соответствие цвета моменту перехода. Отдельно проверяются порядок уровней LONG, новая дорожка, сохранность предыдущих композиций, декодирование и воспроизведение экспортированного MP4.

## Итог проверки экспорта

Финальный MP4: **9 526 380 байт** (меньше обычного лимита GitHub). Все 1395 кадров прошли проверку макета; 23 ключевых кадра — проверку пересечений и читаемости. 25 кадров из закодированного MP4, включая промежуточные состояния переходов, сопоставлены с программным рендером. Полное декодирование H.264/AAC и воспроизведение с перемоткой в Chromium прошли без ошибок. Найденное смещение голоса — 0 отсчётов при 8 кГц; корреляция с оригиналом после AAC-кодирования — 0,999970. В финальном удержании нет добавленного звука. Пять проверенных кадров предыдущего успешного ролика совпали пиксель в пиксель после расширения общих компонентов.
