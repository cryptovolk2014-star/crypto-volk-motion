# Ethereum / DARK — полная тёмная версия и единый масштаб рук

Новая композиция `scan-ai-ethereum-dark` использует существующие сцены Ethereum и тот же движок. Полностью заново отрендерены все 1065 кадров. Продолжительность — 35,5 с, 1080×1920, 30 fps, H.264/AAC. Прежний MP4 `output/crypto-volk-scan-ai-ethereum.mp4` сохранён без изменений.

## Что исправлено

- **Весь ролик остаётся в тёмной теме.** Navy `#050718` — основной фон всех восьми сцен. Панели, карточки, экран телефона, сетки графиков и финальный CTA адаптированы под Navy с Ivory, Violet и Cyan. Цвет кожи рук остаётся естественным.
- Переход к светлому Ivory удалён. На слове «посмотри», в прежнем интервале 3,84–4,56 с, проходит тонкая сканирующая линия Cyan с умеренным свечением поверх Navy. Светлого раскрытия фона нет.
- Экран iPhone полностью тёмный: стекло `#090E23`, строки активов `#121A32`, светлый текст, контрастная подсветка выбранного ETH/USDT, тёмные графики и читаемые уровни. Кнопка Cyan остаётся акцентом.
- **Масштаб правой руки исправлен для обоих нажатий.** Её базовый коэффициент увеличен с 0,53 до 0,82, то есть на 54,7%. Левую удерживающую руку и размер телефона не изменяли. Сравниваются анатомические ориентиры, а не одинаковые габариты исходных картинок: хват и вытянутый палец имеют разные силуэты.
- Ориентиры удерживающего большого пальца и нажимающего указательного пальца дают проекции около 375 и 452 px в контакте, соответственно. Соотношение 1,206 одинаково при выборе ETH и нажатии AI-анализа; до исправления указательный палец выглядел непропорционально коротким. Это контроль масштаба по вручную выбранным ориентирам, дополненный визуальным просмотром двух жестов.
- Точки касания остались на тех же кнопках. Сохранены подход, небольшое сжатие/наклон при касании и отвод руки. Величина правой руки не меняется при переходе от одного жеста к другому.
- Озвучка, сценарий, порядок сцен, торговые уровни и тайминги сохранены. Новая музыка и эффекты в звук не добавлялись. Конец содержит прежние 2,089387755 с тишины для чтения CTA.
- Оригинальные прозрачные Crypto Volk / Scan AI и фотографические слои рук сохранены побайтно. Повторной генерации изображений нет.

## Архитектура и редактирование

`compositions/scan-ai-ethereum-dark.js` переиспользует сценические функции предыдущего ролика. Новый JSON-профиль включает `themeMode: "dark"` и `phoneOptions: {screenTheme: "dark", rightHandScale: 0.82}`. Общие сцены и компонент телефона расширены опциями, старые настройки по умолчанию сохранены. Пять контрольных кадров предыдущей Ethereum-композиции после расширения общих компонентов совпадают с сохранёнными превью пиксель в пиксель.

- `compositions/scan-ai-ethereum-dark.json` — все параметры, тайминг, уровни и калибровка.
- `components/phone-demo.js` — светлая/тёмная тема экрана и независимый масштаб правой руки.
- `components/dark-scan.js` — сканирующая линия, не меняющая фон на светлый.
- `assets/audio/scan-ai-ethereum.mp3` и `compositions/scan-ai-ethereum-words.json` — прежняя запись и её проверенная разметка.
- `output/scan-ai-ethereum-dark/contact-sheet.jpg` — основные сцены.
- `output/scan-ai-ethereum-dark/hand-comparison.jpg` — два исправленных нажатия рядом.
- `output/scan-ai-ethereum-dark/phone-journey.jpg` — выбор → нажатие → анализ → сценарий.

Демонстрационный LONG: Stop 3 150 < Entry 3 300 < TP1 3 450 < TP2 3 600 < TP3 3 750. Метка «ДЕМО» сохранена. Исходные свойства продукта и предложение трёх бесплатных сигналов следуют прежней озвучке; сценарий не является текущей торговой рекомендацией.

## Запуск

```sh
npm ci --cache .npm-cache
npm start
```

Просмотр: `http://localhost:4173/composition.html?composition=scan-ai-ethereum-dark`.

```sh
npm run check:ethereum:dark
npm run stills:ethereum:dark
npm run render:ethereum:dark
npm run check:ethereum:dark:media
```

Нужны Node.js, Chromium и FFmpeg/ffprobe. Дополнительные зависимости, ASR-модели и генерация изображений не требуются. Итог: `output/crypto-volk-scan-ai-ethereum-dark.mp4`.

Проверяются все 1065 кадров: кегль от 36 px, границы текстов, кириллица, сохранность бренда, согласованность LONG-уровней, отсутствие дрожания букв. На ключевых кадрах дополнительно проверяются отсутствие светлого фона и светлого экрана телефона, контраст тёмной темы, пересечения надписей, действительные координаты контакта и проецируемый масштаб рук. После экспорта проверяются полный декодированный MP4, воспроизведение/перемотка и сохранённая синхронизация голоса.

## Итог экспорта

Финальный MP4: **7 132 762 байта**, меньше обычного лимита GitHub. Полное декодирование и воспроизведение с перемоткой в Chromium прошли без ошибок. Проверены все 1065 кадров и 23 кадра из закодированного MP4, в том числе оба нажатия с исправленным масштабом. Смещение голоса — 0 отсчётов при 8 кГц; корреляция с исходной записью после AAC — 0,999968. Конечное удержание содержит тишину. В 16 ключевых превью нет пересечений текстов и бренда, тёмный экран телефона подтверждён пиксельными пробами.
