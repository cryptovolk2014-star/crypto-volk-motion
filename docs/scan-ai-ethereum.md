# Ethereum на ладони — Crypto Volk Scan AI

Новая самостоятельная композиция `scan-ai-ethereum` в существующем Crypto Volk Motion Engine. Визуальный эталон — успешная версия `scan-ai-clarity`. Её исходники, озвучка, превью и MP4 сохранены, как и более ранние ролики.

## Что добавлено

- Новая запись из пользовательского ZIP: **33,410612245 с**. Полный экспорт — **35,5 с**, **1065 кадров**, **1080×1920**, **30 fps**, H.264/AAC. В конце — 2,089387755 с тишины для удержания CTA. Музыка, изменение темпа и характера голоса не добавлены. Исходный MP3 сохранён побайтно; экспорт AAC 256 kbit/s.
- Новая история: противоречивые сигналы по Ethereum → раскрытие светлой темы → iPhone с демонстрацией Scan AI → 20 000+ пользователей → самостоятельная проверка → три бесплатных сигнала → CTA.
- Формулировки «20 000+» и «три бесплатных сигнала» следуют новой озвучке. Они не перенесены из сценариев предыдущих рекламных версий. Транскрипция записи: `compositions/scan-ai-ethereum-script.txt`.
- Переиспользуемый компонент `components/phone-demo.js`: левая рука удерживает iPhone; отдельная правая рука подходит к цели по плавной траектории, касается кнопки, слегка меняет наклон/сжатие и отходит. Координаты касаний откалиброваны относительно стекла. На кадре касания кнопка ещё видна; анализ начинается после короткой фазы нажатия.
- Фотореалистичные слои телефона/рук подготовлены отдельно. Это новые материалы, созданные с помощью генерации изображений. Предоставленные фотографии используются только как ориентиры для камеры и положения рук. Их интерфейс, чужой условный знак, экранные тексты, фон и декоративные предметы не копируются. Происхождение и SHA-256 — `assets/phone/manifest.json` и `assets/references/ethereum/manifest.json`.
- Весь интерфейс телефона — программная графика: реальные Montserrat / Roboto Mono, выбор ETH/USDT, кнопка запуска, сканирование свечей и зон, LONG-сценарий с входом, стопом и целями. Изображения с готовым текстом интерфейса не генерировались. Оригинальные прозрачные Crypto Volk и Scan AI используются без изменений.
- Добавлен геометрический многогранный знак Ethereum с контролируемым поворотом и светом в фирменной палитре. Новые сцены используют существующие панели, тени, свечи, типографику и переходы.
- Общий график адаптирован под разные активы: свечи нормализуются относительно входа и первого целевого уровня. При исходном BTC-сценарии поведение остаётся прежним. До экспорта проверяется сохранность предыдущих композиций.

## Демонстрационный сценарий

ETH/USDT, LONG: **Stop 3 150 < Entry 3 300 < TP1 3 450 < TP2 3 600 < TP3 3 750**. FVG 3 345–3 393, Order Block 3 195–3 248; диапазон графика 3 075–3 825. Все свечи и аналитические зоны используют ту же ценовую систему. На телефоне и в рамке сцены видна метка «ДЕМО». Интерфейс стилизованный, это не текущая торговая рекомендация и не точная копия реального продукта. Светлая тема обозначает ясность подачи, а не отсутствие риска.

## Запуск и редактирование

```sh
npm ci --cache .npm-cache
npm start
```

Просмотр: `http://localhost:4173/composition.html?composition=scan-ai-ethereum`.

```sh
npm run check:ethereum
npm run stills:ethereum
npm run render:ethereum
npm run check:ethereum:media
```

Нужны Node.js, Chromium (`/usr/bin/chromium` или `CHROMIUM_PATH`), FFmpeg/ffprobe. ASR-модели и генерация изображений для повторного рендера не нужны: все слои и разметка находятся в проекте.

- `compositions/scan-ai-ethereum.js` — восемь независимо редактируемых сцен.
- `compositions/scan-ai-ethereum.json` — границы сцен, касания, переход темы, уровни ETH, список превью и путь экспорта.
- `components/phone-demo.js` — компоновка экрана, калибровка стекла и движения правой руки; принимает `events` и `setup`.
- `components/theme-reveal.js`, `fintech.js`, `trading-setup.js` — существующие общие компоненты.
- `output/crypto-volk-scan-ai-ethereum.mp4` — итоговое видео.
- `output/scan-ai-ethereum/` — 16 ключевых превью, общий контактный лист, отдельные листы DARK → LIGHT и последовательности на смартфоне, отчёты проверки.

## Проверки

Программный проход по всем 1065 кадрам: реальные шрифты, кегль от 36 px, безопасные области, корректность кириллицы, ожидаемые английские обозначения и отсутствие ошибок JavaScript. Дополнительно проверяются пересечения надписей, границы интерфейса внутри стекла, контраст светлой темы, стабильность букв, прозрачность и хеши бренда, попадание пальца в ETH и кнопку анализа, порядок реально нарисованных ценовых линий LONG. Полный декодированный MP4 проверяется на параметры, воспроизведение с перемоткой и синхронность исходного голоса; закодированные ключевые кадры сравниваются с программным рендером.

## Итог экспорта

Файл: **7 138 164 байта**, меньше лимита обычного файла GitHub. Полное декодирование и воспроизведение в Chromium с перемоткой прошли без ошибок. 23 кадра из закодированного видео, включая нажатия и переходы, сопоставлены с нативным рендером. Все 1065 кадров прошли проверку макета, а 16 ключевых превью — проверку пересечений текста и бренда. Смещение голоса — 0 отсчётов при проверке на 8 кГц, корреляция с исходной записью после AAC — 0,999968. Музыки нет, финальное удержание содержит тишину. Пять контрольных кадров предыдущей версии `scan-ai-clarity` совпадают пиксель в пиксель после адаптации общего графика.
