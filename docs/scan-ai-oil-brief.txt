Нужно переделать / собрать новый вертикальный моушн-ролик 9:16 под приложенную аудиодорожку и референс с баррелем нефти.
Задача
Сделай премиальный рекламный ролик в стиле Crypto Volk с качественной кинетической типографикой, анимированными графиками, аккуратными плашками и стильной финтех-визуализацией.
Ролик должен выглядеть:
- дорого
- современно
- динамично
- профессионально
- читаемо
- премиально
- в крипто/финансовой эстетике
Исходники
Используй:
1. приложенную аудиодорожку как основу тайминга;
2. изображение с баррелем нефти как визуальный референс для начала ролика.
Главная идея
В начале нужен короткий динамичный хук, связанный с тем, что нефть “сливается” / падает / уходит вниз, а затем ролик переходит в основную часть по тексту из аудиодорожки.
Важное по драматургии
Сделай ролик с понятной эмоциональной дугой:
1) Хук — первые 1–2 секунды
Начало должно быть максимально цепляющим.
Покажи:
- баррель нефти;
- резкое ощущение падения цены;
- слив / пролив / красный импульс / обвал котировок;
- можно использовать анимацию, будто нефть “утекает”, график падает вниз, цена летит;
- визуально это должно быть быстро, мощно, но стильно.
Текст для хука
Используй один главный вариант:
«НЕФТЬ СЛИВАЕТСЯ?»
Дополнительно, если по таймингу красиво влезает, можно коротко добить второй строкой:
«А ТЫ ГОТОВ?»
или
«ЧТО ДАЛЬШЕ?»
Но без перегруза. Главное — чтобы хук был короткий и очень сильный.
Далее — основной текст
После хука ролик переходит в основную подачу строго под аудиодорожку.
Важно:
- не выдумывать новый текст;
- ориентироваться на реальный текст из приложенной озвучки;
- синхронизировать титры и сцены по речи;
- выделять ключевые слова крупнее;
- второстепенные слова делать более тонким шрифтом.
Визуальный стиль
Используй стиль Crypto Volk:
Фирменная палитра:
- Navy — #050718
- Ivory — #F3EFE9
- Violet — #7A52EE
- Cyan — #5FCDC9
Допускаются дополнительные чистые акцентные цвета:
- зелёный
- красный
- жёлтый
- белый
Но без грязных полутонов. Цвета должны быть чистыми, сочными и контрастными.
Цветовая драматургия
Очень важно, чтобы цвет в ролике тоже работал на смысл:
Первая часть:
- более тёмная
- тревожная
- напряжённая
- холодная
- акцент на красный / тёмно-синий / тёмные фоны
Вторая часть:
- более ясная
- технологичная
- уверенная
- “решение найдено”
- акцент на cyan / violet / светлые чистые элементы
То есть ролик должен визуально переходить от проблемы к решению.
Что показывать в кадре
Используй не просто текст, а насыщенный motion design:
Для начала:
- баррель нефти
- падающий ценовой график
- красные свечи
- линии цены
- краткие ценовые метки
- импульс вниз
- эффект “слива”
Для основной части:
- трейдинговые графики
- свечные чарты
- элементы интерфейса
- финансовые UI-элементы
- плашки
- графические акценты
- линии, сетки, HUD-эстетика
- цифры / тикеры / ценовые блоки
- аккуратные интерфейсные карточки
Если в аудио речь идёт о нефти, можно добавлять:
- тикер нефти
- OIL / XBRUSD / WTI / BRENT стилизацию
- сигнальные карточки
- вход / стоп / цели
- short / long плашки
- визуал анализа
Типографика
Сделай качественную кинетическую типографику.
Шрифтовая логика:
Используй два визуальных типа шрифта:
1. Крупный жирный современный гротеск
   - в духе Montserrat Bold / ExtraBold
   - для главных фраз и хуков
2. Более тонкий современный шрифт
   - в духе Montserrat Medium / SemiBold / Light
   - для поясняющих строк, подзаголовков и маленьких плашек
Важно:
- буквы должны быть стабильными
- без дрожания
- без “прыгающего” кернинга
- без орфографических ошибок
- всё должно быть читаемо
- текст не должен быть слишком мелким
Размер текста
- Главные фразы — крупные и акцентные
- Мелкий текст — сделать заметно крупнее, чем обычно
- Никаких слишком маленьких подписей, которые трудно читать на телефоне
Композиция
Сделай грамотную безопасную композицию под соцсети:
- весь важный текст держать в безопасной зоне;
- не прижимать к самому низу;
- не размещать слишком близко к краям;
- если есть нижние элементы интерфейса Instagram / TikTok, учитывать safe area.
Анимация
Нужна качественная motion-графика:
- плавные переходы
- энергичные входы текста
- стильные вылеты плашек
- графики могут собираться по частям
- UI-элементы могут всплывать слоями
- цифры, стрелки, свечи, маркеры могут оживать
- анимация должна быть живой, но не хаотичной
Главное:
- всё должно “двигаться красиво”
- без перегруза
- без визуального мусора
- без ощущения шаблонности
Что особенно важно
1. Сохранить премиальный стиль Crypto Volk
2. Начать с короткого мощного хука про слив нефти
3. Дальше чётко идти по аудиодорожке
4. Сделать сильную кинетическую типографику
5. Сделать хороший баланс между текстом и графикой
6. Все тексты — без ошибок
7. Мелкий текст увеличить
8. Сделать ролик цепляющим с первых секунд
9. Использовать баррель нефти как визуальный референс только для начала, не обязательно копировать буквально
10. Финал должен ощущаться как уверенное решение / сильный CTA
Итог
Собери готовый вертикальный рекламный motion-видео ролик 9:16, в котором:
- есть сильный стартовый хук;
- есть визуал барреля нефти и падения нефти в начале;
- есть качественная синхронизация с аудио;
- есть фирменный стиль Crypto Volk;
- есть премиальная моушн-графика;
- есть читабельные крупные титры;
- есть плавный переход от проблемы к решению.
