# Scan AI / Нефть — отдельная тёмная композиция

Новый ролик собран в существующем Crypto Volk Motion Engine. Сохранены движок, локальные шрифты Montserrat и Roboto Mono, стилистика первых роликов, оригинальные прозрачные брендовые PNG, интерфейсные панели и архитектура экспорта. Предыдущие пять финальных MP4 не изменены.

## Что сделано

- Короткий хук «НЕФТЬ СЛИВАЕТСЯ?» с объёмным фотореалистичным баррелем, красными свечами и импульсом вниз. Изображение пользователя служит визуальным референсом; отдельный прозрачный слой барреля подготовлен для монтажа. Логотипы при этом не генерируются и не перерисовываются.
- Полностью новая последовательность сцен по новой озвучке: прогноз → план сделки → AI-анализ → вход / цель / риск → Telegram → три бесплатных анализа → выбор нефти.
- Весь ролик остаётся тёмным. От напряжённого красного вступления он переходит к ясной структуре Cyan/Violet на Navy. Светлая тема не включается.
- Новый переиспользуемый компонент `components/commodity-market.js`: десятичные цены, согласованный SHORT/LONG-сценарий, свечи OHLC, сканирование, зоны и уровни. Все аналитические сцены показывают один и тот же график.
- Крупная устойчивая типографика; программная отрисовка настоящими шрифтами. Минимальный кегль 36 px; основные интерфейсные подписи 38–46 px. Текст по смыслу озвучки, вместо непрерывной ленты субтитров.
- Очищенные оригинальные Scan AI и Crypto Volk без внешних прямоугольных подложек. Фирменное тёмное внутреннее пространство неоновой плашки сохраняется.

BRENT / XBRUSD, SHORT. Stop Loss **79,60 > Entry 78,40 > Take Profit 76,20**. Дополнительные цели конфигурации 75,00 / 73,80 не выводятся одновременно, чтобы не перегружать короткую озвученную фразу. На видео присутствует маркировка «ДЕМО · НЕ КОТИРОВКА». Это стилизованный интерфейс и пример структуры, без утверждения о текущем рынке, доходности или гарантии результата.

## Запуск и редактирование

Требуются Node.js, Chromium и FFmpeg с libx264. При необходимости путь Chromium задаётся переменной `CHROMIUM_PATH`. Для контактного листа нужен Python 3 + Pillow.

```sh
npm ci --cache .npm-cache
npm start
```

Открыть `http://localhost:4173/composition.html?composition=scan-ai-oil`.

```sh
npm run check:oil
npm run stills:oil
python scripts/contact-sheet.py --composition=scan-ai-oil
npm run render:oil
npm run check:oil:media
```

- `compositions/scan-ai-oil.js` — независимые функции восьми сцен.
- `compositions/scan-ai-oil.json` — длительность, границы сцен, ключевые слова, уровни, превью и пути.
- `compositions/scan-ai-oil-script.txt` — транскрипция новой записи.
- `docs/scan-ai-oil-brief.txt` — исходный пользовательский бриф.
- `components/commodity-market.js` — переиспользуемая финансовая графика; другие композиции не переписаны.
- `assets/commodities/oil-barrel.png` — прозрачный предметный слой; происхождение и хеш в соседнем manifest.

MP4: `output/crypto-volk-scan-ai-oil.mp4`. Превью всех ключевых сцен, контактный лист, отдельный обзор «нефть → анализ» и отчёты: `output/scan-ai-oil/`.

## Проверка перед выдачей

`check:oil` проверяет все 801 кадр: реальные границы глифов в безопасной области, кегль, смешение алфавитов, стабильность осевшего текста, наличие новой озвучки по хешу, речевые якоря, отсутствие случайных английских слов и светлых сцен. В ключевых кадрах дополнительно проверяются пересечения текста и брендовых изображений. Проверяются альфа-каналы оригинальных плашек и барреля, фактически нарисованные линии SHORT, хеши всех предыдущих MP4.

`check:oil:media` декодирует весь MP4, сверяет его с программным рендером основных сцен и переходов, проверяет реальные параметры H.264/AAC, 1080×1920, 30 fps, 801 кадр, нулевой временной сдвиг голоса и тихое финальное удержание. Дополнительно проверяет воспроизведение и перемотку Chromium и HTTP Range 206.
