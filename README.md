# Crypto Volk · Scan AI

Вертикальный motion design ролик об AI-анализе золота, синхронизированный с предоставленной озвучкой. 1080×1920, 30 fps, 25,156 секунды. Палитра: `#050718`, `#F3EFE9`, `#7A52EE`, `#5FCDC9`. Montserrat и Roboto Mono, лицензии рядом с файлами шрифтов.

## Результат

- `output/crypto-volk-motion-final.mp4` — готовый H.264 / AAC ролик с оригинальным фирменным оформлением, сохранённый обычным Git (7 510 609 байт, меньше 100 MB).
- `assets/timeline.json` — тайминг, смысл и акценты сцен.
- `motion.js` — детерминированная покадровая анимация; время берётся из оригинальной озвучки.

Графики и интерфейс созданы для иллюстрации речи. Это не реальные котировки, не обещание доходности и не запись работающего продукта. Музыка не добавлялась; сохранена загруженная озвучка целиком. Осциллограмма внизу следует амплитуде этой записи.

## Фирменные изображения

Оба изображения извлечены из предоставленного пользователем ZIP и сохранены без изменения байтов:

- `assets/brand/scan-ai-banner.png` — оригинальная горизонтальная плашка Scan AI, 2172×724;
- `assets/brand/cryptovolk-trade.png` — оригинальный логотип Crypto Volk Trade, 1200×1200;
- `assets/brand/manifest.json` — исходные имена, размеры и SHA-256 каждого файла.

Плашка используется в сценах 4 и 8, логотип — в финальной сцене. Изображения не перерисовывались, не генерировались через AI и не перекодировались. При монтаже сохраняются полные изображения и их пропорции; анимация меняет масштаб, положение и прозрачность слоя. Отсутствие исходного изображения останавливает загрузку, чтобы экспорт не заменил его текстовым титром незаметно.

Ссылка/имя Telegram-бота в исходных материалах не указаны: финальный CTA не содержит выдуманного адреса.

## Запуск и экспорт

Нужны Node.js 24, FFmpeg с libx264 и Chromium. В подготовленной облачной среде они уже установлены. После клонирования репозитория:

```sh
cd crypto-volk-motion
npm ci
npm start
```

Открыть локальный сервер порта 4173 в браузере; нажать «Воспроизвести со звуком». Слайдер позволяет проверить произвольное время. Сервер поддерживает Range-запросы для перемотки аудио и MP4. Порт можно изменить через `PORT`.

В текущей облачной среде checkout находится в `/workspace/crypto-volk-motion`; для доступного кэша npm используйте `npm ci --cache /workspace/.npm-cache`.

```sh
npm run stills
npm run render
```

`npm run stills` создаёт восемь PNG-превью в `output/`. `npm run render` создаёт или обновляет `output/crypto-volk-motion-final.mp4`. Зависимости, ZIP-архивы, промежуточные кадры, черновые экспорты, временные файлы и кэши исключены из Git; в `output/` отслеживается только финальный MP4.

Экспорт полностью локальный. Шрифты и аудио не загружаются со сторонних сайтов. Chromium вызывается из `/usr/bin/chromium`; альтернативный путь задаётся через `CHROMIUM_PATH`. FFmpeg кодирует JPEG-кадры Canvas с CRF 17, пиксельным форматом yuv420p, AAC 256 kbps и faststart.

Используйте существующий checkout; отдельный Git worktree для работы не нужен. Пакеты распознавания речи и их модели, использованные при разметке, не требуются для воспроизведения или повторного экспорта.
